# Config pipeline loses overrides and state between calls

The small service in `src/index.mjs` resolves configuration from three layers: built-in defaults, a caller's file settings, and an environment-like object. Operators noticed that a partial file override can erase a sibling setting, and values such as `APP_RETRIES=0` or `APP_ENABLED=false` sometimes appear to be ignored. A later call may also inherit changes made by an earlier one. Repair the pipeline without changing its exported API or the public tests.

`resolveConfig({ file = {}, env = {} } = {})` returns a new object with this shape: `{ network: { endpoint: string, retries: number }, ui: { theme: string, compact: boolean }, enabled: boolean }`. Defaults are endpoint `localhost`, retries `3`, theme `light`, compact `false`, enabled `true`. The precedence is defaults < file < env. A file layer may provide any subset of only these listed top-level or nested fields. For `network` and `ui`, merge their immediate fields, so an override of one field keeps its siblings. The env layer recognizes `APP_ENDPOINT`, `APP_RETRIES`, `APP_THEME`, `APP_COMPACT`, and `APP_ENABLED`; present values override the corresponding file field. Env values are strings: retries is one or more decimal digits, including leading zeros such as `"00"`, whose numeric value is at most `Number.MAX_SAFE_INTEGER`; compact and enabled are exactly `"true"` or `"false"`. Invalid values for recognized env keys throw `TypeError`. Missing keys have no effect. Other env keys are ignored. A caller may pass ordinary, non-null, non-array objects for `file` and `env`; invalid layer objects throw `TypeError`.

The final fields must satisfy the validator: endpoint and theme are nonempty strings, retries a nonnegative safe integer no greater than `Number.MAX_SAFE_INTEGER`, compact and enabled booleans. Do not mutate or retain nested references to the file layer, env layer, or exported defaults. A result or input from one call must not affect another call. Keep the existing `formatLegacy(config)` output exactly `endpoint=<endpoint>;retries=<retries>;enabled=<on|off>`; `formatConfig(config)` must keep that exact prefix and append `;theme=<theme>;compact=<yes|no>`. In particular, `false` and `0` must survive every layer and the legacy output must still accept the resolved object.

The package includes independent identifier, cache-key, and log-level utilities used elsewhere by the service. Their behavior is unrelated to this config fix. The hidden checks exercise the documented pipeline and compatibility behavior; they do not require changes to these utilities.
