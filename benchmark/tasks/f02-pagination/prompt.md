Implement `paginate(items, page, pageSize)` in `pagination.mjs`.

`items` must be an array. `page` and `pageSize` must be positive safe integers. Reject a non-array with `TypeError` and either invalid numeric argument with `RangeError`. The first page is 1. Return `{ items, totalPages, nextPage }`, where `items` is a new array containing the selected elements in original order; `totalPages` is `Math.ceil(items.length / pageSize)`; `nextPage` is the next 1-based page number only if that page exists, otherwise `null`. Empty input has zero pages and returns empty page data and `nextPage: null`. A page beyond the last returns empty page data and `nextPage: null`, while preserving the actual total page count. Do not mutate the input array or its elements. Keep the named export.
