Fix `createCounter` in `counter.mjs` while preserving its named export. Each call creates an independent counter. `createCounter(initial = 0)` starts at the supplied finite number. The returned object has `value()`, `increment(step = 1)`, and `decrement(step = 1)` methods. `value()` returns the current number; increment and decrement update that instance by the finite numeric step and return the new value. Both positive and negative finite steps are allowed. A non-number or non-finite `initial` or `step` throws `TypeError` without changing any counter. Do not change the public tests.
